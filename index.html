Performance que dá para medir, na própria página

Uma aplicação de conteúdo com renderização híbrida (prerender + SSR), hidratação incremental, imagens otimizadas e um painel que mede LCP, CLS e INP no seu navegador.

Técnicas aplicadas

🧩

Hidratação incremental

Blocos @defer com hydrate on viewport/interaction: o HTML vem pronto, o JS só quando necessário.

🔁

Event replay

Cliques e digitação antes da hidratação são capturados e reexecutados depois.

🖼️

NgOptimizedImage

priority + fill + sizes no hero para melhorar o LCP e evitar layout shift.

📦

Cache HTTP / TransferState

O que o servidor buscou é serializado no HTML: zero requisição duplicada no cliente.

🗂️

Renderização híbrida

Prerender em páginas estáticas, SSR por requisição em páginas com dados.

🔎

SEO completo

Title, description, Open Graph, canonical e JSON-LD por rota, mesmo no HTML do servidor.
