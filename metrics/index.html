SSR vs CSR

O mesmo build serve as duas versões: ?csr=1 entrega apenas o shell do cliente, sem HTML renderizado no servidor. Abra cada uma, volte aqui e compare as medições salvas neste navegador.

Esta versão publicada no GitHub Pages é 100% estática: todas as páginas foram pré-renderizadas no build e não há servidor Node, API Express nem modo ?csr=1. A comparação SSR vs CSR ao vivo só funciona rodando o servidor SSR localmente (veja o README); aqui valem as medições de referência e as medições salvas neste navegador.

Como cada técnica ajuda

  • LCP: HTML pronto no servidor + NgOptimizedImage priority (preload, fetchpriority).
  • CLS: imagens com fill + aspect-ratio e placeholders de @defer com altura reservada.
  • INP: menos JS na hidratação (hidratação incremental) e event replay.
  • Rede: cache de transferência HTTP evita o segundo fetch; rotas lazy reduzem o bundle inicial.
